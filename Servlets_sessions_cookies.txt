Servlets
Servlets are the java program that extends the capabilities of physical server to build the web application
Basically there are two main Interfaces

1.HttpServletRequest
2.HttpServletResponse

Servlet methods
init()-- once called  Handles servlet resources
doPut()-- basically used to update operations
doGet()-- to get the operations
doDelete()-- to delete the operations
doPost()-- to post the operations
doDestroy()-- destroys/cleanup before the servlet is destroyed

Servlet Lifecycle
Init()-- called once
Service() -- called for handling the client request
Destroy() --- cleanup before the servlet is destroyed
